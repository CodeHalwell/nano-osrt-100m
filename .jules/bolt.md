## 2024-05-30 - [Explicit device-to-host syncs in generation loop]
**Learning:** Checking for stop tokens with explicit python `for` loops inside the autoregressive decoding step causes repeated host-to-device memory syncs, which slows down generation significantly, especially since the `stop_token_ids` check triggers on every single generated token.
**Action:** When evaluating termination tokens in PyTorch, use `torch.isin` and pre-allocate the stop tokens into a tensor *outside* the generation loop. Do not allocate the `stop_tensor` on the device *inside* the decoding loop either, as it causes memory transfer overhead per-step.
